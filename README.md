# Digital-Wallet-System
The Digital Wallet System is a secure web-based platform enabling users to store, transfer, and manage money online. Built with PHP, MySQL, and JavaScript, it provides fast transactions, user authentication, admin control, and data encryption for a reliable digital payment experience.
🧾 Project Description:

The Digital Wallet System is a secure web-based application designed to simplify online transactions by allowing users to store, manage, and transfer money digitally. It eliminates the need for cash or physical cards by enabling users to perform financial activities such as adding funds, transferring money, paying bills, and viewing transaction history using a single, easy-to-use web interface.

The system is developed using PHP, HTML, CSS, JavaScript, and MySQL, ensuring dynamic functionality, responsive design, and efficient database operations.
It includes a powerful Admin Module to monitor and manage users, transactions, and overall wallet activity.

🎯 Objectives:

To provide a secure platform for digital money management.

To enable users to perform financial transactions such as fund transfer and bill payments online.

To maintain transaction transparency with complete history tracking.

To enhance data security through encryption and role-based access control.

To support an admin interface for user management, fraud detection, and report generation.

⚙️ Modules:
🧍 User Module

User registration and secure login

Add money to wallet

Send and receive funds

View balance and transaction history

Edit profile and password

Notifications for transactions

🧑‍💼 Admin Module

Manage users and verify accounts

Approve or block suspicious accounts

Monitor transactions and generate reports

Manage wallet limits and fees

Ensure data integrity and security

🧠 Security Module

User authentication and password encryption

Role-based access control (User/Admin)

Fraud detection alerts

Two-factor authentication (2FA) support

Secure session management

🗃️ Technology Stack:
Component	Technology
Frontend	HTML, CSS, JavaScript, Bootstrap
Backend	PHP (with MySQLi / PDO)
Database	MySQL
Server	XAMPP / Apache
Security	MD5 or bcrypt password hashing, session tokens, input validation
💡 Key Features:

Secure user authentication system

Real-time wallet balance updates

Transaction history with filters and export option

Admin panel for oversight and analytics

2FA-based login and session timeout

Data encryption for sensitive information

Fraud detection and anomaly alerts
